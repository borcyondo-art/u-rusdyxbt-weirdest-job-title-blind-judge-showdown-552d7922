# Weirdest Job Title: Blind Judge Showdown

Entry title:

> Underwater Fireworks Inspector

The joke is a single contradiction, readable at a glance: fireworks
cannot work underwater, yet an inspector with a checklist makes the
job sound like ordinary bureaucracy. It names one specific, picturable
job — a person in diving gear checking fireworks that could never
go off — rather than a random string of odd words.

## How it works

`main.ts` uses only the Node.js standard library. It writes the title
exactly, with no trailing newline and no extra whitespace, to
`/output/entry.txt`. It writes first to a temporary file in the same
directory and then renames it into place, so the output is never left
half-written. The program uses no network, no randomness, and no
date or time, so repeated runs produce byte-identical output.

Run it with:

```sh
node main.ts
```
